# Mini ERP CRM – Frontend

## 📌 Project Overview

Mini ERP CRM is a web-based Enterprise Resource Planning and Customer Relationship Management application. The frontend provides a simple and user-friendly interface for managing customers, products, challans, and viewing business information through a dashboard.

The frontend is developed using **React, TypeScript, Vite, HTML, and CSS** and communicates with the backend through REST APIs.

## 🚀 Features

- User Login and Authentication
- JWT-based authentication
- Dashboard
- Customer Management
- Product Management
- Challan Management
- REST API integration
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- HTML5
- CSS3
- REST API
- JWT Authentication
